В конце каждого урока теперь есть дополнительная кнопка **«Отметить и перейти к следующему уроку»**. Она сохраняет прогресс и ведёт к следующему независимому HTML-файлу. # Магия Математики — 1.0.1

**Интерактивный автономный атлас математики** в чёрно-зелёном стиле. Начни с `index.html`.

## Содержимое

- 15 основных разделов, **104 отдельных HTML-урока** и 416 задач с обратной связью.
- 3D-карта: **золотой** — пройдено; **ярко-зелёный** — доступно по рекомендованным предпосылкам; **приглушённый** — есть ещё неотмеченные предварительные темы.
- Кнопка **⇢** над картой переключает тематические связи на ориентированные связи **необходимых знаний** между разделами (пунктир со стрелкой). Никакая страница не заблокирована.
- У каждого урока — краткая карта понимания, базовая модель и формула, обоснование или честно названный самостоятельный разбор, эксперимент, четыре задачи и ссылки на соседние знания.
- 39 прежних предметных доказательств/выводов из v0.9.0 и **6 новых** поясняющих выводов: дифференциальные формы, теория меры, интеграл Лебега, гармоники Фурье, пространства Lᵖ, распределения.
- 22 прежние специализированные лаборатории и **6 новых** математических Canvas-экспериментов. Остальные уроки сохраняют прежние лаборатории.
- Два механизма прогресса: ручная отметка **✓** и дополнительная **★**, когда решены все четыре задачи. ★ не отменяет ручного режима.

## Как запускать

1. Скачай ZIP и распакуй его **полностью**, не изменяя внутреннюю структуру.
2. Открой `magiya-matematiki/index.html` в современном браузере.
3. Все математические тексты, стили, Canvas и сценарии встроены в каждую страницу; соединение с интернетом не требуется.
4. Для наиболее надёжного общего хранилища между страницами можно выполнить `python3 -m http.server 8000` в каталоге `magiya-matematiki` и открыть `http://localhost:8000/`. Использовать сервер **не обязательно**: уроки передают отметку на атлас также в URL при возврате. Поведение `localStorage` при `file://` зависит от браузера.

## Данные прогресса

В каталоге есть **Экспортировать прогресс (.json)** и **Импортировать прогресс**. Импорт объединяет положительные отметки из резервной копии с текущими и ничего не стирает. Невалидные и неизвестные ключи не импортируются. Все данные остаются на устройстве.

Ключи совместимы со старыми версиями:

- `magic-math:lesson-progress:v1` — золотые отметки по `sector::Название урока`.
- `magic-math:mastery:v1` — ★: все четыре задачи решены.

Прогресс между **разными браузерами и компьютерами** не синхронизируется автоматически: используй экспорт и импорт.

## Архитектура

- `index.html` — атлас, 3D-граф, каталог, данные прогресса и интерфейс импорта/экспорта.
- `lessons/<section>/<slug>.html` — полностью независимый HTML-файл каждого урока, со встроенными CSS и JS.
- `curriculum.json` — 104 темы и ориентированные учебные зависимости (декларативные метаданные; страница главного атласа содержит те же правила встроенно для работы без сетевых запросов).
- `lesson-manifest.json` — полный список уроков v1.0.
- `lesson-manifest-v0.8.1.json` — архив предыдущего справочника.

Чтобы добавить урок, добавь новый HTML, затем объект в `sectors` и зависимости в `mmPrerequisites` внутри `index.html`. Название и ID опубликованных уроков не переименовывай без миграции данных прогресса.

## О границах математического содержания

Это **первая полноценная бета-версия учебного атласа**, а не замена математическим учебникам и независимой экспертизе. 45 уроков теперь содержат конкретные доказательные выводы или тщательно ограниченные математические обоснования; в оставшихся 59 уроках сохранены **самостоятельные разборы**, которые нельзя выдавать за доказанные теоремы. Четыре задания на страницу проверяют базовые навыки, а не дипломную квалификацию. Численные и графические модели иллюстрируют специальные случаи, но не заменяют общих доказательств. Полная предметная рецензия всех математических утверждений ещё нужна.

## v1.0.2 — мобильный просмотр

- На iPhone в быстром просмотре HTML (например, приложение «Файлы») JavaScript часто не выполняется. Теперь главная показывает запасную статическую карту 15 разделов и полный каталог 104 уроков с обычными ссылками без JavaScript.
- В Safari по опубликованному HTTP(S)-адресу работает интерактивный 3D-атлас и сохранение прогресса. Не путайте быстрый просмотр файла с полноценным запуском сайта.
- Исправлено наложение кнопок на заголовок атласа на узких экранах и исходные счётчики для предпросмотра.
- Все идентификаторы уроков и ключи прогресса сохранены.


## v1.0.3 · Внутренний просмотр и iPhone

- Главная `index.html` дополнительно содержит статический читатель **всех 104 уроков внутри того же HTML-файла**. Названия уроков в атласе ведут к якорям `#read-...` — файл не пытается открыть соседнее вложение внутри изолированного предпросмотра ChatGPT или iOS Quick Look.
- Ссылка `↗ HTML` ведёт на оригинальный автономный интерактивный урок, если каталог распакован и открыт в обычном браузере. Полные лаборатории, проверка задач, золотые отметки и звёзды работают именно там.
- Статический читатель включает исходную теорию, примеры, блоки доказательств и упражнения с раскрываемыми объяснениями, но **не заменяет** лаборатории с canvas и автоматические отметки.
- На ограниченных iPhone-просмотрщиках переходы по якорям зависят от возможностей конкретного приложения. Для полноценной навигации Safari с локальным веб-сервером или HTTPS остаётся предпочтительным способом запуска.

ГЛАВА 01 / 03

Что делает преобразование равносильным

Тождество утверждает, что два выражения равны для всех значений из общей области определения. Мы вправе группировать слагаемые, раскрывать скобки, выносить общий множитель.

(a + b)² = a² + 2ab + b²
РАЗБОР / ШАГ ЗА ШАГОМ

Раскроем произведение: (a + b)(a + b) = a² + ab + ba + b². Для действительных чисел ab = ba, значит средние члены дают 2ab.

Граница утверждения. Формула (a + b)² = a² + b² неверна в общем случае: пропущен смешанный член 2ab.

ГЛАВА 02 / 03

Вынесение множителя

Распределительный закон работает в обе стороны. Он позволяет сократить количество операций и увидеть общую структуру выражения.

6x + 9 = 3(2x + 3)
РАЗБОР / ШАГ ЗА ШАГОМ

Вынесем общий множитель 3, потому что 6x = 3 · 2x и 9 = 3 · 3.

Граница утверждения. Нельзя сокращать слагаемые в дроби по отдельности: (x + 2)/x не равно 2 для общего x.

ГЛАВА 03 / 03

Область определения не исчезает

Некоторые преобразования меняют формальную запись, но требуют сохранить исходные ограничения. Это важно в рациональных выражениях.

(x² − 1)/(x − 1) = x + 1, x ≠ 1
РАЗБОР / ШАГ ЗА ШАГОМ

Числитель равен (x − 1)(x + 1). При x ≠ 1 сокращаем множитель x − 1. При x = 1 исходная дробь не существует.

Граница утверждения. Даже если упрощённая формула вычисляется в точке, это не делает исходное выражение определённым там.

04 / САМОСТОЯТЕЛЬНЫЙ МАТЕМАТИЧЕСКИЙ РАЗБОР

Разверни определение: Тождества и преобразования

Опирайся на введённое выше определение и разобранный пример. Для освоения темы полезно уметь самостоятельно восстановить путь от предпосылок до вывода.

  1. Выпиши все обозначения и область объектов, к которым относится утверждение. Не пропускай слова «для всех», «существует», «при условии».
  2. Объясни, что означает каждый символ в формуле: (a + b)² = a² + 2ab + b². Укажи, где она определена.
  3. Повтори разобранный пример самостоятельно. Замени одно числовое значение или одну предпосылку и проверь, останется ли утверждение истинным.
  4. Найди контрпример к слишком сильной версии утверждения (без одного из условий). Если контрпример не получается, поясни, почему.

⚑ Здесь приведён план самостоятельной проверки, а не новое доказательство теоремы. Для полного вывода потребуется отдельная расширенная глава.

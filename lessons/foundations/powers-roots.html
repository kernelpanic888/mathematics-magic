ПОНЯТИЕ / 01

Степени

При натуральном n выражение aⁿ — произведение n одинаковых множителей a. Например, 2³ = 2 · 2 · 2 = 8.

aᵐ · aⁿ = aᵐ⁺ⁿ

Для a ≠ 0 принято a⁰ = 1 и a⁻ⁿ = 1/aⁿ. Например, 2⁻³ = 1/8. Эти правила согласуются с умножением степеней.

ПОНЯТИЕ / 02

Корень — обратный вопрос

Арифметический квадратный корень √a — единственное неотрицательное число, квадрат которого равен a; для действительных чисел необходимо a ≥ 0.

√9 = 3   ·   √(5²) = 5

С другой стороны, уравнение x² = 9 имеет два решения: x = 3 и x = −3. Символ √9 обозначает только 3 — не «±3».

ПОНЯТИЕ / 03

Кубические и другие корни

Кубический корень ∛a — действительное число, куб которого равен a; он существует и при отрицательном a.

∛8 = 2   ·   ∛(−8) = −2

Важно: корень не обязан быть целым. Например, ∛3 — точное число между 1 и 2, приблизительно 1,442. Приближение не заменяет точного обозначения ∛3.

ПОНЯТИЕ / 04

Модуль и условия

Из определения главного квадратного корня следует:

√(a²) = |a|

Например, при a = −5 получаем √25 = 5, а не −5. Для действительных a ≥ 0 верно √a · √a = a.

Формула √(ab) = √a√b в действительной арифметике применяется при a ≥ 0 и b ≥ 0; забывать условия нельзя.

05 / САМОСТОЯТЕЛЬНЫЙ МАТЕМАТИЧЕСКИЙ РАЗБОР

Разверни определение: Степени и корни

Опирайся на введённое выше определение и разобранный пример. Для освоения темы полезно уметь самостоятельно восстановить путь от предпосылок до вывода.

  1. Выпиши все обозначения и область объектов, к которым относится утверждение. Не пропускай слова «для всех», «существует», «при условии».
  2. Объясни, что означает каждый символ в формуле: aᵐ · aⁿ = aᵐ⁺ⁿ. Укажи, где она определена.
  3. Повтори разобранный пример самостоятельно. Замени одно числовое значение или одну предпосылку и проверь, останется ли утверждение истинным.
  4. Найди контрпример к слишком сильной версии утверждения (без одного из условий). Если контрпример не получается, поясни, почему.

⚑ Здесь приведён план самостоятельной проверки, а не новое доказательство теоремы. Для полного вывода потребуется отдельная расширенная глава.
